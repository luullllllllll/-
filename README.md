# 兴中化肥厂人员管理系统

> 面向兴中化肥厂的移动端人员管理系统 —— 员工档案、职位、论坛交流与公告中心，前端原生实现，开箱即用。

## 项目简介

本项目是一个纯前端的单页人员管理系统，为兴中化肥厂提供员工档案管理、职位一览、论坛交流与公告发布等能力。系统采用移动端优先的交互设计，支持登录 / 注册、人员增删改查、帖子与公告查看，并将数据持久化到浏览器本地（localStorage），无需后端即可体验完整流程。

## 功能特性

- **登录 / 注册**：内置管理员账号，支持新用户注册，登录后进入主工作台（登录/注册区自动隐藏）
- **人员管理**：员工档案列表、按姓名 / 工号 / 职位搜索、新增 / 编辑 / 删除人员
- **职位管理**：按职位自动汇总在册人数
- **论坛交流**：浏览帖子、查看详情、发布新帖
- **公告中心**：查看厂内公告及详情
- **管理员控制台**（仅管理员可见）：系统数据概览、角色分布、重置 / 清理数据
- **数据持久化**：数据保存在浏览器 localStorage，刷新不丢失
- **响应式布局**：移动端优先，桌面端亦可正常使用

## 技术栈

- **原生 HTML / CSS / JavaScript**：零依赖、单文件自包含
- **Font Awesome 6**：图标库（经 jsDelivr CDN 引入）
- **localStorage**：本地数据持久化

## 快速开始

1. 直接下载并打开 `兴中化肥厂管理系统.html`，或部署到任意静态托管（GitHub Pages 等）
2. 使用默认管理员账号登录体验：

| 账号 | 密码 | 角色 |
| --- | --- | --- |
| admin | 123456 | 管理员 |
| zhangwei / lili / wangfang | 123456 | 员工 |

3. 也可在登录页切换"注册"，注册后自动登录进入系统

## 说明

- 系统为前端演示版本，账号与业务数据保存在浏览器本地，不涉及服务端存储
- 默认内置 4 名人员、2 篇帖子与 2 条公告作为示例数据，可在管理员控制台重置或清理
